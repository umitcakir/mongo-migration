# Contributing

## Development

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm test` before opening a pull request.
4. Run `npm start` to exercise the local web interface.

Keep changes focused, avoid committing credentials or generated `dist/` files,
and update the README when user-facing behavior changes.

## Pull requests

Describe the user-visible change, how it was tested, and any MongoDB versions
or deployment environments affected. Small, focused pull requests are easier
to review.
